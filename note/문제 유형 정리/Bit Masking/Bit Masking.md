비트 마스킹(비트마스크)은 **정수의 이진 표현(bit)을 이용하여 여러 상태를 한 변수에 압축해서 저장**하고, 이를 통해 효율적으로 연산하는 기법이에요.  
특히 **부분 집합, 방문 체크, 조합 탐색 등**을 빠르게 수행할 수 있어서 PS(Problem Solving)에서 많이 사용돼요.

---
## 🔹 비트마스킹의 핵심 개념

정수형 변수 하나를 이용해 **최대 32개의 상태(32bit 정수)**를 저장할 수 있어요.

```c++
int mask = 0;

// 3번째 비트 켜기 (0-based index)
mask |= (1 << 3);   // mask = 00001000

// 2번째 비트 확인
if (mask & (1 << 2)) {
    // 2번째 비트가 켜져 있음
}

// 3번째 비트 끄기
mask &= ~(1 << 3);  // mask = 00000000

// 토글 (켜져 있으면 끄고, 꺼져 있으면 켜기)
mask ^= (1 << 1);

// 특정 비트가 켜져 있는 개수
__builtin_popcount(mask); // GCC/Clang 전용 (count of 1's)
```

>[!note]
>이해를 위해서는 대수와 Polynomial을 다루는 방법에 대해서 이해를 하면 좀 더 쉽게 이해가 가능함.

## 🔸 자주 나오는 유형

### ✅ 1. 부분 집합 (Subsets) 문제

```c++
// n개의 원소가 있을 때, 모든 부분집합 탐색 
for (int bit = 0; bit < (1 << n); bit++) {     
	for (int i = 0; i < n; i++) {         
		if (bit & (1 << i)) {             
			// i번째 원소가 포함된 상태         
		}     
	} 
}
```

💡 `1 << n`은 `2^n`개의 부분집합을 의미해요.

---

### ✅ 2. 방문 체크 (DFS/BFS)


```c++
int visited = 0;  
void dfs(int cur) {     
	visited |= (1 << cur);      
	for (int next : adj[cur]) {         
		if (!(visited & (1 << next))) {             
			dfs(next);         
		}
	} 
}
```

✔️ 메모리 절약 + 연산 속도 빠름

---

### ✅ 3. 최소 거리 탐색 (DP + 비트마스크)

예시: **외판원 순회 (TSP)**
```c++
int dp[16][1 << 16]; // 최대 16개 도시 
// dp[cur][visited]: 현재 도시가 cur이고 visited 상태일 때 최소 비용
```

- 시간복잡도: `O(N^2 * 2^N)`
- 메모리: `N * 2^N`
